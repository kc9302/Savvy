# Savvy: 저장됨 취향 지도

인스타그램에 저장해 둔 게시물이 수천 개 쌓이면 다시 찾아보기 어렵고, 내 관심사가 무엇인지도 한눈에 안 보입니다. 이 프로젝트는 저장 목록을 주제별로 나누고, 언제 많이 저장했는지 보여주는 단일 HTML 페이지입니다.

- 서버가 없습니다. 파일을 선택하면 브라우저 안에서만 읽고, 어디로도 전송하지 않습니다.
- 폰 화면을 기준으로 만들었습니다. 인스타에서 받은 ZIP을 압축 해제 없이 그대로 고릅니다.
- 의존하는 외부 라이브러리는 ZIP 해제용 JSZip 하나이고, CDN에서 불러옵니다.

## 할 수 있는 것

첫 화면은 "찾기" 탭입니다. 가상 사용자 시뮬레이션에서 찾기 우선형(검색 → 주제 칩 → 세부 칩 → 카드)과 폴더형의 개수 표시를 합친 구조가 가장 많은 지지를 받았습니다(`docs/simulation-feedback-v2.md`).

| 기능 | 설명 |
|---|---|
| 불러오기 | 인스타 내보내기의 ZIP, JSON, HTML을 읽습니다. 한글이 깨져 저장된 JSON도 복원하고, 같은 게시물은 한 번만 셉니다. 파일을 고르기 전에는 예시 데이터가 보입니다. |
| 찾기 | 검색창, 주제 칩(개수 표시), 주제를 누르면 열리는 세부 태그 칩(개수 표시), 결과 카드. 카드에서 태그를 떼거나 붙이고, 어떤 키워드 때문에 분류됐는지 보여줍니다. |
| 주제와 세부 태그 | 주제 31개는 하나만 붙고(위쪽 규칙이 우선), 세부 태그는 맞는 것이 모두 붙습니다. 운동 안에 목·거북목, 어깨, 허리·코어, 골반·고관절, 스트레칭 등 13개, 커리어·재테크·맛집·요리·살림·가족·여행·마음에도 세부 태그가 있습니다. |
| 내 취향 보기 | 전체 개수, 가장 많이 저장한 주제, 주제별 막대, 월별과 일별 저장 빈도, 유형 카드(주제 이름과 비율만, 이미지 저장). |
| 직접 고치기 | 분류 규칙은 화면에서 편집할 수 있고, 항목마다 주제와 태그를 바꿀 수 있습니다. 모두 그 기기에 저장됩니다. |
| 노션으로 옮기기 | 노션에서 가져올 수 있는 CSV(UTF-8, BOM 포함, 세부 태그 열 포함)를 내보냅니다. |

외부 요청이 없습니다. ZIP 라이브러리(JSZip, MIT)는 파일 안에 내장했고 외부 폰트도 쓰지 않습니다. 개발자도구 네트워크 탭에서 확인할 수 있습니다.

## 쓰는 법

### 1. 인스타에서 내 데이터 받기

1. 인스타 앱 → 설정 및 활동 → 계정 센터 → 내 정보 및 권한 → 내 정보 다운로드
2. 저장한 계정을 고르고 일부 정보에서 **저장됨**만 선택
3. 기기에 다운로드, 기간은 **전체 기간**, 형식은 **JSON**(권장), 미디어 품질은 낮음
4. 준비되면 알림이나 메일의 링크로 ZIP을 받습니다. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.

저장한 계정과 같은 계정으로 요청해야 합니다. 다른 계정으로 요청하면 저장됨이 비어 있습니다.

### 2. 페이지에서 열기

`index.html`을 브라우저에서 열고 "내보내기 파일 선택"으로 ZIP을 고르면 끝입니다. 여러 파일을 한 번에 고르면 합쳐서 보여주고, 다시 고르면 새 파일로 바뀝니다. 파일을 고르기 전에 보이는 화면은 예시 데이터입니다.

### 3. 분류 규칙 바꾸기

페이지 아래 "분류 규칙 고치기"에 한 줄에 하나씩 `주제: 키워드,키워드` 형식으로 적혀 있습니다.

```
수영: 수영,접영,평영,swim
요리: 요리,레시피,집밥,recipe
```

- 캡션이나 계정명에 키워드가 들어 있으면 그 주제로 분류합니다.
- 위쪽 줄이 먼저 적용됩니다. 구체적인 주제를 위에 두세요.
- 영문 키워드는 단어 단위로만 맞습니다. `ai`가 `said` 안에서 걸리지 않습니다.
- 어디에도 안 걸리면 미분류입니다.

## 이 저장소에 없는 것

저장됨 목록을 자동으로 모으거나 공개 페이지에서 캡션을 가져오는 보조 스크립트는 이 저장소에 두지 않습니다. 이 페이지는 인스타그램이 공식으로 제공하는 "내 정보 다운로드" 파일만 읽습니다. 앱의 약관과 안전 문제를 사용자에게 떠넘기지 않기 위해서입니다.

## 내 데이터를 미리 담은 개인용 페이지

파일을 고르는 단계 없이 열자마자 내 저장 목록이 보이는 페이지를 만들 수 있습니다.

```bash
node tools/build-personal.js <saved_posts.json> [crawl_cache.json] [my-saved-map.html]
```

결과 파일에는 내 저장 목록이 그대로 들어 있습니다. `.gitignore`가 `my-saved-map*`을 막지만, 어디에도 공개하지 마세요.

## 개인정보

- 페이지는 선택한 파일을 서버로 보내지 않습니다. 분류 수정과 규칙은 브라우저 저장소에만 남습니다.
- `.gitignore`가 내보내기 파일(`saved_posts*.json`, ZIP, 크롤 캐시)을 막습니다. 내 저장 데이터를 저장소에 올리지 마세요.
- 저장 목록에는 다른 사람의 계정명과 캡션이 들어 있습니다. 가공한 결과를 공유할 때 유의하세요.

## 올려서 쓰기

빌드 과정이 없습니다. `index.html` 한 파일을 어느 정적 호스팅에든 올리면 됩니다. GitHub Pages라면 저장소 설정의 Pages에서 `main` 브랜치 루트를 지정하세요. 페이지를 공개로 올려도 사용자의 파일은 사용자 브라우저 안에서만 처리됩니다.

## 확인한 것과 못 한 것

확인했습니다.
- 2025년 이후 형식 JSON(저장 2,400여 개)의 읽기, 분류, 차트, 목록
- ZIP 안에서 저장됨 파일 찾기, 한글 복원, 중복 제거, 저장됨이 빈 내보내기의 안내 문구
- 폰 폭(390px)에서 가로 넘침 없는 레이아웃

확인하지 못했습니다.
- 실제 폰 브라우저와 아티팩트 같은 샌드박스 안에서의 동작
- HTML 형식 내보내기. 구조를 추측해서 만든 읽기라서 실제 파일로 검증이 필요합니다.
- 분류 정확도. 오분류를 눈으로 확인하며 규칙을 고친 수준이고 정답률은 재지 않았습니다.
- 인스타 공식 내보내기가 저장됨을 얼마나 빠뜨리는지

## 알려진 한계

- 키워드 분류라서 문맥을 이해하지 못합니다. 짧은 글귀나 이미지만 있는 게시물은 미분류로 남기 쉽습니다.
- 임베드나 스크래핑으로 채운 데이터에는 저장한 날짜가 없습니다. 날짜 차트는 공식 내보내기에서 온 날짜가 있는 항목만 그립니다.
- 인스타의 비공식 경로(내부 API, 임베드 페이지)는 예고 없이 막히거나 바뀝니다.
- 스크래핑이 인스타 이용약관상 어떤지 확인하지 않았습니다. 공개 배포나 판매 전에 확인이 필요합니다.
- 노션 앱(폰)에서는 CSV 가져오기가 안 될 수 있습니다. PC 웹에서 하는 편이 안전합니다.
