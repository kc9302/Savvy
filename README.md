# 저장됨 취향 지도

인스타그램 저장됨 목록을 주제별로 나누고, 언제 많이 저장했는지 보여주는 단일 HTML 페이지입니다. 서버가 없고, 파일은 브라우저 안에서만 읽습니다.

## 쓰는 법 (폰 기준)

1. 인스타 앱에서 내 정보 다운로드를 요청합니다. 저장됨만, 전체 기간, JSON 형식을 고릅니다.
2. 준비되면 받은 ZIP을 폰에 저장합니다. 압축을 풀 필요가 없습니다.
3. 이 페이지를 열고 "내보내기 파일 선택"으로 ZIP을 고릅니다.

`index.html` 한 파일이 전부라서 정적 호스팅 어디에든 올릴 수 있습니다. 로컬에서는 파일을 더블클릭해서 PC 브라우저로 열면 됩니다.

## 하는 일

- ZIP, JSON, HTML을 읽습니다. 한글이 깨져 저장된 인스타 JSON도 복원합니다.
- 캡션과 계정명의 키워드로 약 30개 주제로 분류합니다. 규칙은 화면에서 고칠 수 있고, 항목별로 주제를 바꿀 수도 있습니다.
- 주제별 개수, 월별과 일별 저장 빈도, 검색, 카드 목록을 보여줍니다.
- 노션에서 가져올 수 있는 CSV를 내보냅니다.

## 확인한 것과 못 한 것

- 확인함: 2025년 이후 형식의 JSON(저장 2,400여 개), ZIP 안에서 저장됨 찾기, 중복 제거, 빈 내보내기 안내.
- 확인 못 함: HTML 형식의 실제 내보내기 파일, 폰 브라우저에서의 실제 동작, 분류 정확도(수치로 재지 않았습니다).
- 인스타 내보내기가 저장됨을 얼마나 빠뜨리는지 모릅니다. 현재 계정의 완전한 내보내기로 아직 비교하지 못했습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 전체 |
| `tools/crawl.js` | 선택 사항. 내보내기에 캡션이 부실할 때 공개 임베드 페이지로 계정명과 캡션을 채우는 Node 스크립트. 로그인 불필요 |
| `tools/collect_saved.js` | 선택 사항. 내보내기가 비어 있을 때 쓰는 콘솔 붙여넣기 수집 스크립트. 본인 계정으로 실행하므로 본인 책임으로 사용 |
| `docs/simulation-feedback.md` | 가상 인물 6명으로 상품화 가능성을 점검한 기록 |

## 주의

- 스크래핑 도구는 인스타 이용약관상의 위치를 확인하지 않았습니다. 공개 배포나 판매 전에 확인이 필요합니다.
- 인스타의 비공식 경로는 예고 없이 막히거나 바뀝니다.
