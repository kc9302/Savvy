# 릴스 대본 (m2)

목표: 반응 확인. 이 릴스로 보려는 것은 "저장을 못 찾는 문제에 공감하는 사람이 프로필 링크까지 오는가"이다. 기준은 `docs/success-criteria.md`를 따른다.

## 1편(1순위): "저장 2,436개, 못 찾겠다" (약 25초)

| # | 시간 | 화면 | 자막 | 소리/말 |
|---|---|---|---|---|
| 1 | 0~4초 | 인스타 저장됨 목록을 빠르게 스크롤(썸네일만, 계정명이 안 보이게 아래 "촬영 주의" 참고) | 저장 2,436개. 그 레시피 어디 갔지 | 스크롤 소리, 한숨 |

| 4 | 13~19초 | 검색을 지우고 주제 칩 줄(전체 32, 운동 4 …)을 보여 준 뒤 "운동"을 누르자 세부 칩이 나오고 카드에 `허리·코어` 태그가 붙어 있음 | 주제별로 갈라서 보여 줘요 | 효과음 |

| 마무리 | 25초 | 프로필 화면 | 링크는 프로필에 | |

## 캡션(그대로 복사)

> 저장해 둔 게 너무 많아서 못 찾는 사람 손.
> 인스타에서 받은 내 저장 파일을 올리면 주제별로 정리해서 보여 주는 작은 웹페이지를 만들었어요. 파일은 내 폰 안에서만 처리해요(서버에 안 올라가요).
> 준비물: 인스타 앱의 "내 정보 다운로드"로 받은 ZIP(받는 데 시간이 걸려요). 링크는 프로필에 있어요.

## 촬영 주의

- **실제 저장 목록과 계정명을 화면에 넣지 않는다.** 1번 장면은 썸네일만 빠르게 지나가게 하고, 계정명과 캡션이 읽히면 흐리게 처리한다. 3~5번 장면은 페이지의 **예시 데이터**만 쓴다. 이 페이지는 내 파일을 안 고르면 예시가 뜨고 위에 "예시 데이터입니다" 배너가 보이는데, 숨기지 않는다(예시임을 숨기면 안 된다).
- 자막의 "2,436"은 내 실제 저장 개수라서 쓸 수 있다. 예시 화면의 숫자는 예시 숫자다. 예시 화면의 숫자를 내 것처럼 말하지 않는다. 필요하면 "예시 화면이에요" 자막을 3~5번에 작게 넣는다.
- **쓰지 않는 표현**: "인스타 공식", "100% 안전", "해킹 걱정 없음", "자동 분류 정확". 분류는 키워드 추정이라 틀릴 수 있다.
- 내 데이터가 폰 밖으로 안 나간다는 말은 "내 폰 안에서만 처리해요"까지만 쓴다. 호스팅 서비스의 접속 기록은 남을 수 있다고 페이지의 고지에 적혀 있다.
- 개인 계정명과 이메일이 화면에 나오지 않게 한다(프로필 화면은 공개 프로필이라 괜찮음).

## 촬영 전 준비

- [ ] 폰에서 https://kc9302.github.io/Savvy/ 가 크롬이나 사파리로 열리는지 확인
- [ ] 화면 녹화로 3~5번 장면을 한 번에 찍는다(검색어 "허리" → 칩 → 카드 → 취향 탭). 10-07에 검색하면 주제 칩과 세부 칩의 숫자도 검색 결과에 맞게 바뀌도록 고쳤다(배포 후 1~2분 뒤 적용). 촬영 전에 폰에서 새로고침해 `전체 1 · 운동 1`처럼 줄어드는지 확인한다

## 2편, 3편 후보(1편 반응을 보고 정한다)

- 2편: "지난달 저장한 레시피 3초 만에 찾기" — 검색창에 입력하자 칩 숫자가 줄어드는 화면(예시 데이터는 "레시피" 검색)
