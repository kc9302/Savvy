# 지인 시험 안내 (m1)

목적: 5명 중 3명 이상이 혼자 완주하는지, 막히면 어디서 막히는지 본다. 기준은 `docs/success-criteria.md`의 공개 전 관문을 따른다.

## 시험 전에

- 5명은 인스타 저장을 평소에 쓰는 사람으로 고른다. 개발에 익숙한 사람만 5명이면 결과가 낙관적으로 나오니 **비개발자를 2명 이상** 넣는다.
- 가능하면 아이폰과 안드로이드를 섞는다.
- **도와주지 않고 지켜본다.** 막혀도 먼저 알려 주지 않는다. 1분 넘게 못 움직이면 "어디가 막혔어요?"만 묻고, 그 지점을 기록한다.
- 지인의 저장 목록 내용은 묻지 않고 기록하지 않는다. 화면을 캡처해 달라고 하지 않는다.

## 지인에게 보낼 메시지(그대로 복사)

> 인스타에 저장해 둔 게시물이 너무 많아서 못 찾는 걸 도와주는 작은 웹페이지를 만들었어. 5분만 써 보고 어디서 막혔는지 알려 줄래?
>
> 주소: https://kc9302.github.io/Savvy/
>
> 먼저 인스타 앱에서 "내 정보 다운로드"를 요청해야 해서 파일이 오기까지 시간이 걸려(몇 분에서 몇 시간). 요청 방법은 페이지의 "파일 받는 방법"에 나와 있어.
> - 내 저장 목록은 내 폰 밖으로 나가지 않아. 비밀번호도 안 물어봐.
> - 막히면 그냥 막힌 곳을 알려 줘. 못 쓰겠으면 그것도 도움이 돼.
> - 크롬이나 사파리로 열어 줘. 인스타 앱 안에서 열면 파일 선택이 안 될 수 있어.

## 관찰 단계 (한 명당 한 줄씩 체크)

| 단계 | 내용 |
|---|---|
| A | 주소를 열었다 |
| B | "파일 받는 방법"을 찾아 읽었다 |
| C | 인스타 앱에서 내 정보 다운로드를 요청했다 |
| D | 파일이 도착한 뒤 페이지로 돌아왔다 |
| E | ZIP을 선택했다 |
| F | 결과 화면이 나왔다 |
| G | 검색이나 주제 칩으로 원하는 게시물을 찾았다 |

완주는 **F까지 혼자 도달**한 경우로 센다. G는 가치 확인용이다.

## 끝나고

1. 완주(F ○) 수를 센다. 3명 이상이면 관문 통과.
2. 2명 이하이면 가장 많이 막힌 단계 하나를 고치고 같은 방법으로 재시험한다. 이유가 기기 문제(파일 선택 불가 등)면 원인부터 해결하고 공개를 보류한다.
3. 결과와 막힌 곳 요약을 이 파일 아래에 날짜와 함께 적고, 업무 추적의 m1을 갱신한다.
