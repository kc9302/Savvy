# 분류 정확도 측정 (표본 100개)

일반 사용자와 같은 조건(캡션만, 계정명 없음)에서 주제가 맞게 붙는지 쟀다. 개발자 본인 저장 2,436개 중 무작위 100개(고정 시드)를 뽑았다. 이 문서에는 개수와 키워드만 적고 캡션 내용은 적지 않는다.

## 방법

1. 분류기의 답을 가린 채 판정자 2명(각 50개)이 캡션만 읽고 주제 하나와 세부 태그를 정했다. 판정자는 같은 계열의 모델이다.
2. 분류기 결과와 비교해 **일치 43개, 불일치 57개**였다.
3. 불일치 57개를 내가 하나씩 읽고 "분류기의 답도 합리적인가"를 다시 판정했다. 합리적이면 허용, 아니면 틀림으로 셌다.

## 결과

| 기준 | 맞은 수 | 비율 |
|---|---|---|
| 엄격(판정자와 일치) | 43 / 100 | 43% |
| **허용 포함(합리적인 답도 맞음)** | **57 / 100** | **57%** |
| 분류기가 주제를 붙인 93개만 보면(허용 포함) | 50 / 93 | 54% |

- 허용 14개는 해시태그만 있는 글, 사색 글처럼 주제가 애매한 경우, 두 주제가 모두 가능한 경우(맛집과 나들이 등)다.
- 틀림 43개 중 5개는 내용이 없는 글(태그나 이미지 설명뿐, 해시태그뿐)에 분류기가 주제를 붙인 경우이고, 나머지 38개는 다른 주제가 분명한 글을 잘못 붙인 경우다.
- 세부 태그: 주제가 일치한 43개 중 태그가 붙은 항목에서 정밀도 약 81%(25 / 31), 재현율 약 81%(25 / 31). 표본이 작아 참고용이다.

## 틀리는 패턴 (분류기가 주제를 붙인 단어)

한 단어에 끌려가는 경우가 대부분이었다. 글 전체의 주제와 상관없이 아래 단어가 있으면 그 주제로 갔다.

| 주제로 잘못 간 곳 | 원인이 된 키워드(표본에서 확인된 것) |
|---|---|
| 사업/마케팅(틀림 9개로 가장 많음) | 창업, 가게, 브랜드, 인사이트, 마인드, 유튜버, 성공 |
| 글귀/명언 | 인생, 행복, 용기, 낭만 |
| 커리어/성장 | 영어, 직장인, 연봉, 자기계발 |
| 수영 | "수영"이 장소나 이름 속에 있을 때 |
| IT/개발 | 알고리즘, 타임라인 |
| 유머/밈 | ㅋㅋㅋ |
| 맛집 | 맥주, 식당, 맛집 해시태그(여행 글에도) |
| 책 | 작가, 책추천 |

원인은 두 가지다. 키워드 하나로 주제를 정하는 규칙이고, 위쪽 주제가 먼저 이기는 순서(사업/마케팅 등이 위에 있음)다. 내용이 없는 글에도 해시태그 한 단어로 주제가 붙는다.

## 한계

- 한 사람의 저장 목록 100개다. 다른 사람은 다를 수 있다.
- 판정자도 모델이고, 불일치 재판정은 내가 했다. 사람이 다시 보면 수치가 달라질 수 있다. 허용 기준은 주관이 들어간다.
- 정확도를 화면에 표시하지는 않았다(업무 추적 s4의 두 번째 절반). 표시할 만큼 근거가 쌓이지 않았다.

## 다음

규칙을 고친 뒤 **다른 시드로 새 표본 100개**를 뽑아 다시 잰다(같은 표본으로 고치면 그 표본에만 맞는 규칙이 된다). 고칠 후보:
1. 해시태그만 있고 글이 없는 항목은 미분류로 둔다.
2. 모호한 단어(가게, 브랜드, 인사이트, 인생, 행복, 알고리즘, ㅋㅋㅋ, 작가)는 단독으로는 주제를 정하지 못하게 하거나 점수를 낮춘다.
3. 주제 순서 대신 맞은 키워드 수나 글 앞부분 가중으로 정한다.
