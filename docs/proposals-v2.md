# 대시보드 구성안 4개 (2026-10-07)

기준 버전은 git 태그 `v0.1-baseline`과 `docs/backup/index-v0.1-baseline.html`에 백업되어 있다.

가상 사용자 8명의 1·2라운드 평가에서 드러난 갈림을 축으로 만들었다. 찾기형 사용자(워킹맘, 운동 영상 저장 직장인, 대학생, 금융권)는 첫 화면이 검색과 세부 분류이길 원했고, 구경형 사용자(저장 습관만 있는 헤비 유저, 취향 분석을 좋아하는 취준생, 디자이너)는 통계와 유형 카드를 원했다.

## 공통 바탕 (네 안 모두 동일)
- 파일을 올리기 전에 샘플 데이터로 완성된 결과 화면을 먼저 보여준다.
- 파일 안내는 한 줄("이 파일은 폰 밖으로 나가지 않아요")이고, 확인법(비행기 모드 시험, 읽는 항목 목록, 소스 링크)은 "자세히 보기"로 접는다.
- 내 정보 다운로드 요청 뒤 "완료 메일이 오면 이 주소로", "홈 화면에 추가" 안내를 둔다.
- 카드마다 원본 링크가 있고 주제를 직접 바꿀 수 있다. 분류 규칙은 화면에서 고친다.

## A안. 취향 통계형 (현재 구조)
큰 숫자 → 한 줄 요약 → 주제 순위 막대 → 저장 빈도 그래프 → 검색과 카드 목록. 세부 주제 없음.
- 강점: 한눈에 보인다. 이미 동작한다.
- 약점: "그래서 뭐?"가 되기 쉽다. 다시 찾기에 불편하다.

## B안. 찾기 우선형
큰 검색창 → 주제 칩 한 줄 → 누르면 세부 주제 칩 한 줄 더(운동 → 목·거북목, 어깨, 허리·코어, 골반, 스트레칭, 러닝...) → 결과 카드. 통계는 "내 취향 보기" 탭으로 숨김. 한 게시물에 세부 태그 여러 개 허용.
- 강점: 필요한 걸 바로 찾는다. 시간이 없는 사람에게 맞다.
- 약점: 구경하는 재미가 숨는다. 세부 주제를 미리 많이 만들어야 하고 틀리면 눈에 띈다.

## C안. 폴더 탐색형
주제 폴더 그리드(이름과 개수) → 세부 폴더 그리드 → 카드 목록. 상단에 작은 검색창. 통계는 폴더 개수가 대신하고 그래프는 "더 보기" 안. 한 게시물이 여러 세부 폴더에 동시에 들어감. 폴더와 규칙은 사용자가 추가·수정.
- 강점: 인스타 컬렉션과 비슷해 설명이 필요 없다. 구경과 찾기를 둘 다 어느 정도 만족한다.
- 약점: 두 번 열어야 카드가 보인다. 분류가 틀리면 엉뚱한 폴더에 들어가 신뢰가 깨진다.

## D안. 유형 카드형 (공유 중심)
정사각형 결과 카드(유형 이름 한 줄, 상위 주제 3개와 비율, 한마디) → 카드 저장 버튼 → 아래에 주제 순위와 카드 목록. 카드에는 주제 이름과 숫자만, 계정명·캡션은 절대 없음. 주제 숨기기 가능.
- 강점: 결과가 재밌고 보여줄 수 있다. 친구 카드를 보고 따라 하는 경로가 생길 수 있다.
- 약점: 유형 이름이 억지스러울 수 있다. 공유하지 않는 사람에겐 첫 화면이 낭비다. 찾기에 약하다.
