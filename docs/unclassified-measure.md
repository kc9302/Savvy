# 미분류 비율 측정 (일반 사용자 조건)

시뮬레이션에서 "미분류 16개는 개발자 본인 조건의 결과라 착시일 수 있다"는 지적이 나와 조건을 나눠 쟀다. 대상은 개발자 본인의 저장 2,436개이고, 같은 분류 규칙(주제 31개, 세부 태그 37개)을 쓴다. 이 문서에는 개수만 적는다.

## 조건

| 조건 | 뜻 | 일반 사용자와의 관계 |
|---|---|---|
| A | 캡션 + 계정명 + 카드 이미지에서 읽은 글(356개 중 206개에 추천 반영) | 개발자 전용. 일반 사용자는 못 얻음 |
| B | 캡션 + 계정명(공개 임베드 페이지로 보강) | 일반 사용자는 계정명을 못 얻음 |
| **E** | **캡션만(계정명 비어 있음)** | **인스타 공식 내보내기와 같은 조건** |

E 조건의 근거: 이 PC에 있는 다른 계정의 공식 내보내기 파일(33개)을 열어 필드만 확인했다. 게시물마다 `URL`과 `캡션`이 있고 `캡션`은 33개 모두 실제 캡션 전문(길이 중앙값 약 330자)이었으며, `제목`(계정명)은 전부 비어 있었다. 계정 하나의 파일이므로 다른 계정에서도 같은지는 아직 모른다.

## 결과 (2,436개 기준)

| 조건 | 미분류 | 비율 |
|---|---|---|
| A (개발자 전용) | 16 | 0.7% |
| B (캡션 + 계정명) | 139 | 5.7% |
| **E (공식 내보내기와 같은 조건)** | **144** | **5.9%** |

- 이미지 글 읽기는 개발자 본인 데이터에서 미분류를 약 5.7%에서 0.7%로 낮췄다. 일반 사용자 화면에는 이 효과가 없다.
- E 조건에서 캡션이 비었거나 설명 문구뿐인 게시물이 99개(약 4%)다. 미분류 144개 중 대부분이 여기에 해당하므로, 캡션이 없는 게시물은 규칙을 늘려도 분류할 수 없다. 나머지 약 45개는 캡션은 있으나 규칙에 안 걸린 것이다.
- 계정명만 있고 캡션이 없는 조건(D)은 미분류가 2,207개(90.6%)였다. 공식 내보내기는 이 조건이 아니므로 해당하지 않지만, 캡션이 비는 게시물은 사실상 분류가 안 된다는 뜻이다.

## 말할 수 있는 것과 없는 것

- 말할 수 있다: "인스타 공식 내보내기만으로 개발자 본인 저장 약 94%가 주제에 배정된다"(미분류 5.9%).
- 말할 수 없다: 분류가 정확하다는 것. **정확도(배정된 주제가 맞는지)는 측정하지 않았다.** 업무 추적의 s4(표본 100개 정확도)가 이 값을 채운다.
- 다른 사람의 저장 목록에서도 비슷한지는 모른다. 지인 시험 때 화면의 미분류 개수를 같이 받는다(m1).
- 릴스와 소개 글에는 "미분류 16개"를 쓰지 않는다. 쓴다면 E 조건 수치(약 94% 배정)와 "분류는 키워드 추정이라 틀릴 수 있다"를 같이 쓴다.
