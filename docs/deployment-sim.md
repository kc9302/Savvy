# 배포 방식과 시장 반응 확인 시뮬레이션 (2026-10-07)

가상 인물 6명(그로스 마케터, 모바일 앱 개발자, 1인 개발자, 워킹맘 사용자, 취향 분석을 좋아하는 취준생, IT 변호사 겸 신뢰안전 컨설턴트)이 1라운드 독립 평가를 했다. 같은 모델이 연기한 인물이라 실제 반응이 아니며, 수치는 전부 추정이다. 결정이 아니라 점검 순서를 뽑는 용도다.

## 결론 표

| 질문 | 결론 |
|---|---|
| 시작 형태 | 6명 전원이 정적 웹(A). PWA(B)는 반응 확인 뒤 선택, 앱 스토어(C)는 지금 할 이유 없음 |
| 앱이 더 나은가 | 아니다. 두 사용자 인물 모두 "웹 주소가 훨씬 낫다". 앱은 설치와 권한, "내 인스타 정보를 가져가나" 의심이 붙는다 |
| 비용 | A와 B는 0원. C는 등록비(금액 확인 필요)와 심사 1~3주(추정) |
| 측정 | 페이지 안에 분석 도구를 넣지 않는다. 인스타 인사이트(릴스 조회·저장·공유·프로필 방문·링크 탭)와 자발적 피드백(DM, 댓글, "도움이 됐어요" 버튼)으로 잰다 |
| 릴스 | 첫 3초에 "저장 수백 개 중 그걸 못 찾는" 장면. 기능 설명형은 넘긴다. 시연은 더미 데이터로 |
| 가장 큰 위험 | 반응이 없을 때 영상 문제인지 데이터 받기 마찰인지 구분을 못 하는 것. 그리고 "밖으로 안 나간다" 약속이 외부 요청(CDN, 폰트) 때문에 거짓이 되는 것 |

## 다수가 동의한 것

1. **정적 웹으로 시작한다.** 비용 0, 반나절, 심사 없음. 폰에서 ZIP 고르는 마찰은 어느 방식에서도 줄지 않으므로 앱으로 가도 얻는 게 없다.
2. **외부 요청을 0으로 만든다.** ZIP 라이브러리를 CDN에서 받으면 방문자 IP가 제3자에 간다. 파일에 내장하면 "외부 요청 없음"을 말할 수 있다. 변호사와 그로스 마케터가 같은 지적을 했다. 폰트도 같은 이유로 외부 로드를 뺀다.
3. **인앱 브라우저와 실제 폰 검증이 먼저다.** 인스타 앱 안의 브라우저에서 링크를 열면 파일 선택이 제한될 수 있다(확인 필요). iOS는 파일 앱의 다운로드 폴더에서 고르는 흐름이라 안내 캡처가 필요하다.
4. **깔때기의 목표를 "완주"가 아니라 "파일 요청 시작"으로 낮춘다.** 릴스 한 편으로 완주까지 가는 사람은 극소수일 것이라는 데 그로스, 1인 개발자, 두 사용자가 동의했다.
5. **릴스 시연에 실제 저장 목록을 쓰지 않는다.** 타인 계정명과 게시물이 노출된다. "인스타 공식", "100% 안전" 같은 표현을 쓰지 않는다.

## 사용자 인물이 말한 깔때기

| 단계 | 워킹맘(박미경) | 취준생(최아린) |
|---|---|---|
| 릴스에서 멈추는 장면 | "그 레시피 어디 갔지" 스크롤하다 포기하는 장면 | 저장함이 주제별로 갈라지고 "맛집 41%" 한 줄이 뜨는 장면 |
| 가장 흔한 행동 | 저장만 하고 넘김 | 저장만 하고 넘김 |
| 링크까지 갈 가능성 | 3 | 4 |
| 파일 요청까지 갈 가능성 | 2 | 2 |
| 친구에게 보낼 가능성 | 낮음 | 5 (결과가 테스트처럼 보일 때) |

두 사람 모두 "이 릴스도 저장 수백 개 중 하나가 된다"고 말했다. 저장 수를 관심으로 읽으면 과대평가가 된다.

## 공개 전 체크리스트 (인물들의 요구를 모은 것)

- [ ] ZIP 라이브러리 내장, 외부 폰트 제거 → 외부 요청 0 확인(개발자도구 네트워크 탭)
- [ ] 실제 폰 iOS 1대, Android 1대에서 ZIP 선택부터 결과까지. 인스타 인앱 브라우저에서도
- [ ] 파일 고르기 안내: "ZIP은 풀지 마세요", 파일명 예시, 폰 종류별 캡처, 실패 시 대처
- [ ] 고지 3항목: 처리 범위와 예외(호스팅 방문 로그), 인스타·Meta와 무관한 비공식 도구, 사용자 책임과 한계(분류 오류 가능, 브라우저 저장 지우는 법)
- [ ] 스크래핑 보조 도구는 공개판에서 제외
- [ ] 결과 화면에 "도움이 됐어요 / 막혔어요" 자발적 피드백 경로(전송 내용을 화면에 보여줌)
- [ ] 성공·중단 기준을 공개 전에 숫자로 적어 둠

## 첫 2주 (1인 개발자 인물의 4단계)

1. 공개 전 점검: 정적 호스팅 URL, 스크래핑 도구 제거본, 실제 폰 테스트. ZIP 선택이 안 되면 보류.
2. 지인 5명 시험: 완주 여부와 막힌 지점 메모. 5명 중 1명 이하 완주이고 이유가 "데이터 받기"면 안내 개선 1회 후 재시험.
3. 릴스 2~3편: 영상, 짧은 링크, 피드백 버튼. 2편 모두 프로필 방문이 한 자릿수면 다른 채널 1곳 추가.
4. 판정: 사전에 적은 기준으로. 기준을 사후에 바꾸지 않는다.

계속 기준(그로스): 릴스 조회 대비 프로필 링크 탭 1% 이상(첫 주 결과로 보정)이면서 "파일 요청까지 해봤다" 응답 5명 이상. 멈춤 기준: 릴스 3편 모두 프로필 방문이 조회의 0.5% 미만이고 DM·댓글 0건. 이 수치들은 추정이다.

## 릴스 소재 후보 (그로스 인물)

1. 자막 "저장 2,436개, 못 찾겠다" + 끝없이 스크롤되는 저장 목록 화면. 1순위.
2. 자막 "지난달 저장한 레시피 3초 만에 찾기" + 검색창에 입력하자 칩에 개수가 뜨는 화면.
3. 자막 "내 취향 지도 보니 맛집 41%" 같은 주제 비율 화면. 숫자는 실제 값만.

## 한계

1. 같은 모델이 연기한 인물이다. 2. 스토어 등록비, 호스팅 무료 한도, 릴스 링크 정책은 모두 "확인 필요"다. 3. 인스타 인앱 브라우저의 파일 선택 제한은 실기기로 확인하지 않았다. 4. 법무 의견은 영역 이름 수준이며 정식 자문이 아니다.
